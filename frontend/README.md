# Mapping Canvas (P2) — React Flow

A BOM-style visual mapping editor: three columns **PDF field → Source field →
Destination field**. AI-suggested edges (P4) render dashed/amber with a confidence
label; the reviewer clicks an edge to approve or reject it. Only **approved** edges
become the resolver mapping — shown live in the side panel and exportable as JSON.

```
frontend/
├─ index.html
├─ vite.config.js          # /api proxied to the FastAPI backend on :8000
├─ src/
│  ├─ main.jsx
│  ├─ App.jsx              # the canvas + edge review + live mapping preview
│  ├─ styles.css
│  └─ sampleGraph.json     # bundled suggestion graph (generated by the suggester)
```

## Run
```bash
cd frontend
npm install
npm run dev        # http://localhost:5173  (uses the bundled sample graph)
npm run build      # production build -> dist/
```

To drive it from live data, run the API (`uvicorn api.main:app --port 8000`), then
fetch a suggestion graph from `POST /api/v1/mappings/suggest` and feed it to the
canvas instead of `sampleGraph.json`. The approve action maps to
`POST /api/v1/mappings/suggestions/{id}/approve`.

## What it demonstrates
- **Human-in-the-loop mapping:** AI proposes edges; nothing is final until a human
  approves. Edge colors: amber/dashed = SUGGESTED, green = APPROVED, red = REJECTED.
- **Confidence-aware review:** each edge shows a % and the side panel shows the AI's
  reasoning; low-confidence edges are counted in the toolbar.
- **Live materialization:** the side panel recomputes `key_pairs` + `field_bindings`
  from the approved subset exactly like the backend `suggester.to_mapping`.

The regenerate the bundled sample after changing the suggester:
```bash
python - <<'PY'
import csv, json
from suggester import MockSuggester
from orchestrator.resolver import load_json
FX='orchestrator/fixtures'
cols=lambda p:[{'column_name':h,'sample_values':[r[i] for r in list(csv.reader(open(p)))[1:6]]}
               for i,h in enumerate(next(csv.reader(open(p))))]
t=load_json(f'{FX}/template_ncb.json'); t['template_id']='tmpl_demo'
sm=MockSuggester().suggest(t, cols(f'{FX}/source.csv'), cols(f'{FX}/dest.csv'),'ds_src','ds_dst')
json.dump(sm.to_dict(), open('frontend/src/sampleGraph.json','w'), indent=2)
PY
```
